Data Storage Converter

Convert bits, bytes and above — with explicit separation between decimal (SI) and binary (IEC) units. This tool can also show both at once, which is the only way to see the gap that confuses drive shopping.

Two standards, one word

The core of nearly every storage misunderstanding. "Kilobyte" has been used to mean both 1000 bytes and 1024 bytes. Storage manufacturers use 1000 (decimal, SI). Operating systems historically used 1024 (binary), because memory addressing is naturally binary. The IEC later formalised the binary names as kibi-, mebi-, gibi- (KiB, MiB, GiB) to remove the ambiguity — but most software still prints "GB" when it means GiB.

Why your 1 TB drive shows 931 GB

Work it through. The manufacturer sells a decimal terabyte: 1 × 10¹² bytes. Windows reports in binary units but labels them with decimal names:

1,000,000,000,000 bytes ÷ 1024³ (1,073,741,824) = 931.32 GiB

Nothing is missing. Both numbers describe the same byte count; they simply divide by different constants. The 69 GB "loss" is a labelling artefact, and it grows with drive size — at 4 TB the gap is about 372 GB.

Bits versus bytes, and the lowercase-b trap

A byte is 8 bits. Network speeds are quoted in bits (Mb/s, Gb/s) while file sizes are quoted in bytes (MB, GB) — and both use a lowercase-or-uppercase "b" to distinguish them. A 100 Mb/s connection therefore transfers at best about 12.5 MB/s. This single distinction explains most "my download is slower than advertised" complaints.

Which should you use?

  • Comparing or buying drives: use decimal — that is what is printed on the box and on spec sheets.
  • Reading OS file sizes: Windows uses binary units with decimal labels; macOS has used decimal since Snow Leopard.
  • Writing technical docs: use KiB/MiB/GiB when you mean 1024-based, and KB/MB/GB when you mean 1000-based.
