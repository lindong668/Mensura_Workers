Shoe Size Converter

Convert shoe sizes between US (men's and women's), UK, EU, Japan (cm) and China. Size systems are not interconvertible by formula, so this tool matches against an actual size-correspondence chart and shows the full table.

Why shoe sizes cannot be calculated

There is no formula. Length units convert by multiplication; shoe sizes do not, because each system uses a different zero point and a different step size. EU sizes step in "Paris points" (2/3 cm), UK sizes step in 1/3 inch with a separate children's offset, and US sizes use yet another origin. Any tool that applies a single multiplication to convert shoe sizes is approximating a table it should simply be looking up.

The US men's and women's gap

US women's sizing runs approximately 1.5 sizes above men's for the same physical length: a women's US 9 corresponds to a men's US 7.5. Note that width fittings are an entirely separate axis — a "wide" in one brand can be a standard width in another, and no length conversion captures that.

Brand variation is larger than system variation

Two boots both labelled EU 42 can differ by several millimetres internally, because each manufacturer builds on its own last — the foot-shaped form the shoe is constructed around. Athletic brands run small, dress shoe brands often run large, and Italian sizing frequently runs narrow. Treat any conversion as a starting point for trying on, never as a guarantee of fit.

Measure instead of converting

The most reliable method bypasses conversion entirely: trace your foot at the end of the day (feet swell), measure heel-to-longest-toe in centimetres, and match against the manufacturer's own chart. The Japan/cm column in the table below is the closest thing to a universal reference, because it is a direct length rather than an index.
